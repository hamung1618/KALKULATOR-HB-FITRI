Riwayat Invoice Tersimpan

Data tersimpan di perangkat (IndexedDB) dan di server (Supabase). Siapa pun yang membuka link bisa melihat riwayat; untuk menyimpan/menghapus perlu Kode edit. Tetap lakukan Backup berkala.

Catatan penggunaan
  1. Diskon dibagi ke tiap barang secara proporsional terhadap nilai jumlah masing-masing barang.
  2. Harga invoice diasumsikan sudah termasuk PPN; PPN tidak ditambahkan lagi.
  3. Ubah kode, deskripsi, qty, isi per boks, harga, dan diskon sesuai invoice. Kolom hitungan akan otomatis berubah.
  4. Kolom kuning/huruf biru adalah input manual. Isi Tanggal Invoice lalu klik Simpan Invoice. Gunakan Cetak / Simpan PDF untuk laporan.
